# DevKit · 原生开发工具箱

独立窗口的 macOS 开发工具箱，使用 SwiftUI 与 AppKit，不是网页套壳。界面采用系统原生分栏、侧栏材质、圆角面板、SF Symbols 和深浅色适配。所有文本均在本机内存处理，不联网、不上传。

## 运行

解压 `DevKit-1.1.1-macOS-arm64.zip`，双击其中的 `DevKit.app`。也可将它拖到「应用程序」。构建目标为 Apple Silicon；当前开发环境为 macOS 27.0.1。未在其他 macOS 版本或 Intel Mac 上实测。

应用使用本地 ad-hoc 签名，没有 Apple Developer ID 签名及公证。如果下载后被系统阻止，请在确认文件来源后，使用系统「隐私与安全性」中的「仍要打开」。不要关闭系统安全机制。

## 功能

- **代码 Diff**：粘贴两段代码，按行对比；带左右行号、红色删除、绿色新增。支持交换两侧、示例、清空与忽略行首尾空白。每侧最多 4,000 行，合计最多 2 MB。CRLF、CR 和 LF 会统一为换行符；保留末尾空行的差异。属于文本行级对比，不提供语法级或字符级 Diff。
- **JSON**：严格校验、格式化、压缩、复制；2/4 空格或 Tab 缩进，定位错误行列。保留键顺序、重复键、原数字字符串及转义写法；不把大整数转成浮点数。最大 2 MB、嵌套不超过 128 层。不支持 JSON5、注释或尾逗号。
- **Unix 时间戳**：秒/毫秒转日期，以及日期反向转换；支持负时间戳和小数秒。日期格式为 `yyyy-MM-dd HH:mm:ss` 或带 `.SSS`。结果支持复制。
- **UTC 时钟**：UTC+0 与 UTC+8（北京时间）固定并排显示为两个等宽等高的大框，每秒刷新，分别显示日期并可复制时间。下方保留 Unix 秒与本机时间。「自定义 UTC 偏移」折叠区保留原 UTC+x 功能，支持 -12 至 +14，以及 `5.5`、`+05:45` 等整分钟偏移，不改变上方两个固定时钟。
- **下班倒计时**：小框按固定北京时间 UTC+8、周一至周五的 **20:30** 计算；到点显示「已下班」，周六日显示「休息日」。不计法定节假日与调休，不是考勤日历。右侧设置按钮可修改时间（24 小时制 `HH:mm`），保存到本机；无效输入不会保存。工作日零点后开始当天倒计时。

时钟默认排第一。侧栏数字表示工具位置；保留已有工具排序代码，本次未修改或重新验收排序功能。

右上角可选跟随系统、浅色、深色。外观、UTC 偏移、工具顺序与下班时间会保存在本机偏好中；代码、JSON、转换输入不落盘，退出即清除。时钟读取本机系统时间，不另行网络校时。

## 应用图标（1.1.1）

保留原有 `{ }` 花括号轮廓。macOS 26/27 的图标改用 Icon Composer 分层资源：系统 Automatic 背景在亮色外观使用白色，在暗色外观使用深色，前景为青色花括号。`CFBundleIconName=DevKit` 指向 `Resources/Assets.car` 内的原生图标，旧版 macOS 保留 `DevKit.icns` 回退。

图标由 macOS 图标外观设置管理，不受 DevKit 窗口右上角「浅色 / 深色」按钮控制。若系统将图标样式固定为某一外观，则以系统选择为准；跟随系统主题需要使用系统的自动图标外观。更新后的 Dock / Finder 可能短时保留缓存，本次未删除系统缓存、未重启 Dock / Finder。

- `Resources/DevKit.icon/`：自包含原生图标源及透明 PNG 图层。
- `Resources/Assets.car`：使用 Xcode actool 27.2 编译的资源；包含 Aqua、DarkAqua 和 tintable 图标栈。普通应用构建直接复制此资源，不要求每次运行 Icon Composer。
- `Resources/make-icon.swift`：重现透明花括号图层与传统 iconset。

Apple ictool 的 macOS / Design Generation 27 Default 和 Dark 渲染均已实际检查；构建包内的亮暗图标栈、图标元数据及签名验证通过。桌面在本次测试后锁屏，尚未在实际 Dock/Finder 上切换系统主题验证，也尚未重启正在运行的旧版；不能把渲染器预览当作实际主题切换验收。

## 源码与构建

需要 Xcode 命令行工具及可用的 macOS SDK：

```bash
bash test.sh
bash build.sh
```

输出 `build/DevKit.app`。构建脚本用新目录生成、签名和验证，再替换构建输出；已有包保存在 `build/.previous.*`，不会原地覆盖正在运行的已签名应用。

- `Sources/ToolCore.swift`：Diff、JSON、时间转换逻辑
- `Sources/DevKitApp.swift`：应用入口、状态、导航与主题
- `Sources/Components.swift`：原生编辑器及公共控件
- `Sources/TextTools.swift`：Diff 与 JSON 页面
- `Sources/TimeViews.swift`：时间转换与时钟页面
- `Tests/CoreTests.swift`：核心回归测试
