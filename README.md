# DevKit · 原生开发工具箱

独立窗口的 macOS 开发工具箱，使用 SwiftUI 与 AppKit，不是网页套壳。界面采用系统原生分栏、侧栏材质、圆角面板、SF Symbols 和深浅色适配。代码处理均在本机完成。「代码格式化」草稿与「记事本」会自动保存到本机；可选文件夹同步默认为关闭，开启后由所选 iCloud Drive 文件夹同步设置、笔记与临时代码，不经过 DevKit 自有服务器。

## 运行

解压 `DevKit-1.6.3-macOS-arm64.zip`，双击其中的 `DevKit.app`。也可将它拖到「应用程序」。构建目标为 Apple Silicon（arm64）、macOS 14 及以上；当前开发环境为 macOS 27.0.1。未在 Intel Mac 或更早 macOS 版本上实测。

应用使用本地 ad-hoc 签名，没有 Apple Developer ID 签名及公证。如果下载后被系统阻止，请在确认文件来源后，使用系统「隐私与安全性」中的「仍要打开」。不要关闭系统安全机制。

## 功能

- **代码阅读器（1.6.3）**：主侧栏新增入口，页面上半部是打开按钮与最多 5 个最近文件，下方是「默认打开程序」的逐格式开关。代码文件在独立窗口内阅读/编辑，显示逻辑行号与语法高亮，不显示工具侧栏或状态栏；支持 ⌘S 保存、⌘Z 撤销、⌘F 查找，右上角可开「Vim 模式」。通过 Finder「打开方式 → DevKit」或拖到应用图标也进入独立窗口；安装或升级本身不改变系统的任何默认打开方式，只有手动打开某个格式的开关才会生效。
- **代码 Diff**：粘贴两段代码，按行对比；带左右行号、红色删除、绿色新增。支持交换两侧、示例、清空与忽略行首尾空白。每侧最多 4,000 行，合计最多 2 MB。CRLF、CR 和 LF 会统一为换行符；保留末尾空行的差异。属于文本行级对比，不提供语法级或字符级 Diff。
- **代码格式化（1.3.0）**：单框粘贴代码，自动识别语言并原位格式化；详见下方专节。
- **记事本（1.4.1）**：文件夹与笔记列表合并为一栏，右侧正文；顶部菜单选择文件夹及最近删除，搜索与笔记列表在同一侧栏。Markdown 即时样式，本地自动保存；新建、多篇笔记、重命名、标题/正文搜索、置顶、移动文件夹、最近删除与恢复。
- **时间中心（1.4.0）**：合并原「UTC 时钟」和「Unix 时间戳」，仍默认第一。上方双时钟与下班倒计时，下方为同一滚动页内的双向转换；转换时区不改变固定双时钟。
- **Unix 时间戳转换（已集成时间中心）**：秒/毫秒转日期，以及日期反向转换；支持负时间戳和小数秒。日期格式为 `yyyy-MM-dd HH:mm:ss` 或带 `.SSS`。结果支持复制。
- **UTC 时钟**：UTC+0 与 UTC+8（北京时间）固定并排显示为两个等宽等高的大框，每秒刷新，分别显示日期并可复制时间。下方保留 Unix 秒与本机时间。「自定义 UTC 偏移」折叠区支持 -12 至 +14，以及 `5.5`、`+05:45` 等整分钟偏移，不改变上方两个固定时钟。
- **下班倒计时（1.5.1）**：按北京时间 UTC+8，周一至周日各自设置下班时间或休息日，每周自动重复。到点显示「已下班」，休息日不倒计时；卡片显示今天的星期及目标时间。不自动匹配法定节假日与调休。点击右侧设置按钮，逐日开关并填写 24 小时制 `HH:mm`；保存时一次校验整周，无效输入不覆盖已保存值；取消不生效。升级时将原统一时间带入周一至周五，周末沿用休息日；恢复默认为工作日 20:30、周末休息。每周设置在本机持久化，已开启文件夹同步时随设置同步。

时钟默认排第一。侧栏数字表示工具位置。

右上角可选跟随系统、浅色、深色。外观、UTC 偏移、工具顺序、每周下班时间与窗口尺寸属于本机偏好，会按设计保留；**未开启同步时，除代码格式化页草稿及记事本外**，其余工具的文本输入不落盘。时钟读取本机系统时间，不另行网络校时。

## 独立代码阅读/编辑器（1.6.0）

- 打开本机代码文本，不运行代码、不扫描项目、不加载远程资源、不添加 IDE 或 AI 面板；独立窗口保留必要的 macOS 窗口按钮，内容区只有代码与左侧行号。长行使用水平滚动，行号按源文件实际行计数，不按折行计数。
- ⌘S 手动写回原文件；打开和高亮不改源文件，未保存时关窗口或退出会提示保存/放弃/取消。保存前检查文件是否被外部修改，发生冲突时拒绝覆盖；可先复制当前编辑再重新打开。
- 支持 UTF-8（含 BOM）、带 BOM 的 UTF-16/UTF-32；保留 BOM 与统一的 LF/CRLF/CR 换行，混合换行不自动统一。不猜测 GBK/Latin-1 等编码；二进制、文件夹或超过 10 MB 的文件会提示拒绝，不自动转码。
- 语言主要由后缀选择，使用已有本地词法高亮（不是编译器）：Swift、JS/TS、Python、Go、Rust、Java、C/C++、JSON、HTML/XML、CSS、SQL、Shell；未知格式尝试既有检测或纯文本显示。
- 最近文件在本机 `DevKit.recentCodeFiles` 偏好中保存路径，按打开顺序去重并最多保留 5 条；打开同一个文件聚焦已有窗口，不重载或抹掉未保存内容。文件正文及最近路径不参加 DevKit iCloud 同步；原文件若位于用户自己的云盘，仍由该云盘处理。
- 文件关联声明为备用处理器（Alternate），安装后不会抢占任何已有默认应用。若 Finder 尚未显示 DevKit，可通过「打开方式 → 其他」选择本版 DevKit.app。

### 逐格式默认打开（1.6.3）

- 「常用代码格式默认用 DevKit 打开」不是一个总开关，而是每个后缀一个独立开关，三列按字母顺序排开，共 24 项，不含 `.txt`，默认全部关闭。
- 开关状态不另存一份偏好记录，而是每次进入页面、切回前台、以及每 2 秒实时读取系统的当前默认程序，所以显示的就是系统真相；关确认框关得晚、系统已拒绝更改时，开关位会自动回到实际状态。
- 打开某一项时，先在后台把该格式当前的默认应用记进本机 `DevKit.defaultOpenersBackup`，再交给 DevKit；关闭时用这份记录恢复原应用。系统会为每一项单独弹确认框，选「继续使用 DevKit」才算生效，选原来的应用则保持原状。
- 一次只处理一项，处理中该开关置灰并显示等待提示；`LSSet` 返回成功不代表系统已接受，因此改完会轮询等待落盘，超时提示「系统没有接受更改（可能取消了确认）」。
- 没有备份记录时（例如升级前已关联、或记录被清理），关闭后提示到访达手动改回。
- `.ts` 与 MPEG-TS 视频同后缀，系统将其认作 `public.mpeg-2-transport-stream`，因此不在此列；`.tsx` 单独按 `com.microsoft.typescript` 处理。

### 编辑器 Vim 模式（1.6.3）

- 独立编辑器窗口右上角一个开关，状态存在本机 `DevKit.vimMode`，关掉即回到普通编辑。
- 开启后光标处于 Normal 模式，右上角标签显示 `NORMAL`；状态标签随按键实时切换。
- 已支持：`i`、`a`、`I`、`A`、`o`、`O` 进入 Insert；`Esc` 回 Normal 并左移一格；`h`/`j`/`k`/`l` 移动，`0`/`$` 到行首行尾，`w`/`b` 按词移动，`gg`/`G` 到文首文尾，`x` 删除字符，`dd` 删除整行，`yy` 复制整行，`p` 粘贴，`u` 撤销。
- 带 ⌘/⌃/⌥ 的组合键一律放行给系统与 AppKit，不拦截 ⌘S、⌘F 等既有快捷键。

## 记事本与时间中心（1.4.0）

### Markdown 记事本

- **简洁两栏（1.4.1）**：左侧为一个合并侧栏（文件夹下拉选择、搜索、笔记列表），右侧为正文。文件夹不再占独立整栏；管理操作收进省略号菜单。左上角可隐藏整个笔记侧栏，进入纯正文布局；分隔线仍可调整宽度。DevKit 全局工具导航保持不变。
- 原生 NSTextView **即时样式编辑**，不是编辑/预览双框：支持 ATX 标题（1–6 级）、粗体、斜体、删除线、行内代码、围栏代码块、列表/待办语法着色、引用、链接文字样式。非当前行隐藏部分 Markdown 标记，光标所在行显示标记；可随时切到「源码」模式。工具栏插入语法，支持原生撤销。
- 这是轻量 Markdown 子集，不是完整 CommonMark/GFM 实现：嵌套强调、表格排版、数学公式、图片/附件渲染尚不支持；列表与任务框保留文本标记（`- [ ]` / `- [x]`），不是可点击的独立复选框。代码块使用等宽样式，不执行代码；链接仅样式化，不自动访问网址。原始 HTML、脚本及远程图片不执行、不加载。
- Markdown 原文保留，包括中文与 Emoji。样式更新不修改源文本、不加入撤销栈；工具栏编辑可撤销。标题独立编辑，正文支持一键复制 Markdown 原文。
- 标题及正文变化后 **0.35 秒合并保存**，离开页面或正常退出也保存。新建、移动、置顶、删除、恢复立即保存；单篇正文最多 1 MB、库文件最多 20 MB，超限/保存失败有状态提示。
- 删除笔记只移入「最近删除」，保留全文且可恢复，**不会定时自动清除**；移除文件夹会把其笔记移到保留的文件夹，最后一个文件夹不能移除。
- 不与 Apple 备忘录互通，不访问系统备忘录数据；不提供附件或实时协作。可选的 DevKit 文件夹同步见下节，不等于 Apple 备忘录同步；应用没有额外端到端加密。

### 保存位置与安全边界

笔记库：`~/Library/Application Support/com.visero.devkit/Notebook/Library.json`。包含文件夹、标题、Markdown 正文、创建/修改时间、置顶和最近删除状态；目录权限 0700、文件权限 0600，先写同目录临时文件并同步，再原子重命名替换。没有额外加密。**备份时可复制整个 Notebook 文件夹**；应用包升级不会删除它。库读取损坏/失败时暂停编辑且不覆盖原文件。测试与预览使用独立路径，不动正式笔记和代码草稿。此版本不支持多个独立 DevKit 进程同时写同一笔记库。

### 时间中心与导航

UTC+0 / UTC+8 双时钟仍等宽等高；下班设置在 1.5.1 扩展为逐星期设置。Unix 秒/毫秒及日期双向转换并入同页，继续支持 UTC 偏移、错误提示与复制。旧排序中的 `epoch` 入口移除，保留其他入口相对顺序，在末尾补入「记事本」；修正侧栏右键上移/下移目标，菜单快捷键随显示顺序变化。

## 每周下班时间与可选文件夹同步（1.5.1）

- 入口：时间中心 → 下班倒计时右侧设置。周一至周日各一行，开关表示是否工作，下班时间分别保存；不含单日例外或节假日排班。
- 每周设置保存在 `DevKit.workWeekSchedule` 偏好中；旧 `DevKit.workEndTime` 保留用于迁移。未设置新格式时按旧时间初始化工作日，不清空原偏好。设置不受机器本地时区及时间戳转换时区影响。
- 已有的可选 iCloud Drive 文件夹功能随本版保留：在侧栏底部开启，选择同一 Apple 账户的 iCloud Drive 目录，每台 Mac 运行 DevKit 时合并文件；本机未启用 iCloud 云盘时需先在系统设置开启。应用不会代登录 Apple 账户或占用其他应用的 iCloud 容器。
- 同步目录为所选文件夹下的 `DevKit/`，包含 `settings.json`、`notebook.json`、`drafts.json`。每周下班设置新增在 settings 中；接收缺少该字段的旧版数据时不会清掉已自定义的整周设置。两台 Mac 均升级本版才能使用每周独立时间。
- 设置按更新时间合并，格式化/Diff 三个输入分别按更新时间合并；笔记按 ID 取并集并保留较新版本，不提供同篇同时编辑的文本级合并。只在文件夹中写 JSON，传输由 iCloud Drive 负责；DevKit 不提供自己的账号服务或额外加密。
- 此前同步功能尚未完成真实双 Mac iCloud 传输验收；本轮仅验证每周设置的编码、合并兼容与本地持久化，不把本地测试称为跨设备同步成功。

## 隐私与本地代码草稿（1.3.0 沿用）

- **「代码格式化」单框草稿也会落盘**：文件为 `~/Library/Application Support/<bundleID>/CodeDraft.json`。正式版 bundle ID 为 `com.visero.devkit`，即 `~/Library/Application Support/com.visero.devkit/CodeDraft.json`；SwiftUI 预览进程按自身 bundle ID 自动隔离（不写正式目录）；CLI 测试必须注入临时目录覆盖，绝不写真实用户目录。文件内容为一个 JSON 对象：`version`（单调递增序列号）、`text`（框内最新文本，含格式化后的最新结果）、`savedAt`。撤销栈等运行时状态不持久化，重开应用后不可用。
- **目录与文件权限**：草稿目录 `0700`、草稿文件 `0600`（仅当前用户可读写）。应用不做额外加密或混淆，**不声称加密**；安全性依赖系统用户目录权限隔离。
- **写入方式**：先写同目录临时文件（`.CodeDraft.json.<UUID>.tmp`）、设 `0600` 后原子替换；串行写入队列带版本号守卫，旧的异步写不会覆盖新内容。
- **触发时机**：输入变化经 **0.5 秒防抖**合并写；格式化成功、撤销、点击清空、应用退出（`NSApplication.willTerminateNotification` 同步 flush）时立即写盘。启动时只读一次草稿；文件缺失按空草稿处理，文件损坏则置 `readCorrupted` 状态位并按空处理，不清空当前框。
- **清空后保持空**：点击「清空」会把草稿写成空字符串（不删除草稿文件），重开应用该框保持为空。
- **保存结果可见**：写失败置 `writeFailed`、文件损坏置 `readCorrupted` 状态位，并通过主线程草稿通知回调到页面状态栏（保存成功/失败均有提示）；应用不会因写失败崩溃。应用不会直接上传草稿；主动开启文件夹同步后，草稿会写入所选文件夹并由云盘传输。
- 未开启同步时 Diff、Unix 转换输入只在内存处理；开启同步时 Diff 两侧与格式化输入会写入所选同步文件夹。外观、UTC 偏移、工具顺序、每周下班设置及窗口尺寸等偏好按设计保留，不属于「输入清除」范围。
- 源码经 stdin 管道传入引擎、结果经 stdout 返回，不写临时文件、不写入你磁盘上的项目目录，也不执行你的代码。

## 代码格式化（1.3.0）

单框输入、一键格式化，专为临时片段设计，不是整项目重构工具。

- **单框自动语言识别**：粘贴代码后按特征启发式识别语言，识别不准可在下拉框手动切换到具体语言。自动识别不是编译器或完整语法分析器，对模板插值、混合语言片段、生成代码可能判错。
- **原位格式化**：格式化结果直接写回输入框，不弹窗、不切换页面。
- **失败保留原文**：引擎报错（语法不完整、片段不合法）时不替换原文，只在状态栏显示错误，用户输入永远不丢。
- **撤销**：格式化是一次原生编辑操作，可按 `⌘Z` 撤销到格式化前，再按一次重做。
- **离线自包含**：所有引擎随应用内嵌于 `Contents/Resources/Formatters/`（web 运行时与 native 二进制两类），不调用系统 PATH 上的同名工具，不要求预装任何语言工具链，也不需要联网下载任何包。
- **不执行、不上传**：格式化只在本机跑引擎，不读取你磁盘上的项目文件、不执行代码、不联网、不发送任何内容；源码经 stdin/stdout 管道进出，不落临时文件。

### 14 种语言范围与引擎

web 与 native 引擎均已按各自 `manifest.json` 与许可证文件核对（web 另含 `THIRD_PARTY_NOTICES.txt`）。引擎调用统一契约：stdin 传入源码，成功时 stdout 仅输出格式化后文本，诊断走 stderr；任何语法/格式错误非零退出且 stdout 为空（应用据此保留原文）。

| 11 | C | clang-format-safe 18.1.8（LLVM 风格） | native | **不是 C 解析器或编译器**：wrapper 先做 raw-aware 词法 preflight 与括号/引号/块注释计数守恒——未闭合引号、块注释、括号会拒绝（exit 3、stdout 为空、保留原文）；但括号平衡的非法语法（如 `int x = ;`）仍可能被照常格式化，应用不保证对这类输入做完整编译级拦截 |

共同能力边界：只调整缩进、换行、空格与括号位置，**不改变代码语义**；不做 import 整理、不补全、不修语法错误；不分析整个依赖树；按单文件片段处理，不读取项目级配置文件。引擎协议补充：wrapper 输出超 2 MB 时以 exit 5 拒绝；应用侧对引擎 stdout 总量超过 4 MB 会抛错并保留原文，不会把截断内容写回。超出上表 14 种的语言只能在 Diff 等页面查看或语法高亮，不提供格式化引擎。
